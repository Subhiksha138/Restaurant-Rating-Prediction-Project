About RestoPredict

RestoPredict is a machine learning based Restaurant Rating Prediction system.

The application uses restaurant information from the dataset to predict an expected restaurant rating.

The system also provides a dashboard to understand restaurant statistics and rating distribution.

01

Dataset

Restaurant data is collected and prepared for machine learning.

02

Preprocessing

Missing values and categorical data are handled before training.

03

Prediction

The trained model predicts the expected restaurant rating.

04

Analytics

Restaurant statistics are displayed through the dashboard.
